Simple Pygame Platformer

Files:
- main.py      : The main game script. Run with `python main.py`.
- requirements.txt : Pygame requirement (install with pip install -r requirements.txt)

Controls:
- Left / Right arrows or A / D : Move
- Space, W, or Up arrow      : Jump (only when on ground)
- ESC                        : Quit

Notes:
- This is a minimal example that uses rectangles (no external art assets).
- To run: create a virtualenv, install requirements, then run `python main.py` from the project folder.
- Tested with Python 3.8+ and pygame 2.x
